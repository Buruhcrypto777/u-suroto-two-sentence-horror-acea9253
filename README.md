Entry for the make.fun bounty [Two-Sentence Horror](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253).

A pure-stdlib Python program (`main.py`) writes one horror story in exactly two sentences to `/output/entry.txt`:

> My wife writes our grocery list on the fridge every Sunday, and I cross things off as I buy them. This week someone added my name, in her handwriting, right under the milk.

172 characters. The second sentence re-contextualises the first completely: a list of things to be bought — and consumed — now has my name on it. The horror is entirely implied. The program runs offline and produces byte-identical output on every run.
